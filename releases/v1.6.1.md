# Inttegro demos 1.6.1

Version 1.6.1 corrects the FastAPI container's static-asset root so its
Checkout presentation controls load from `/static` in Docker and conventional
Python hosting environments.

## Checkout presentations

Every server-backed demo continues to offer three ways to present the same
server-created, finalized Order:

- **Embedded** Checkout inside the application flow;
- **Modal** Checkout inside an accessible app-owned dialog; and
- **Hosted page** on Inttegro Pages, which remains the no-JavaScript fallback.

API credentials, catalog selection, prices, line items, and finalization stay
on the trusted server. Embedded and modal flows receive only the finalized
Order ID, while ordinary form submissions retain a `303 See Other` handoff.

## Release contract

This release contains 15 tagged demos. The suite tag and every per-demo tag
point to the same signed release commit. Reader deployment branches are
regenerated from that immutable source, and the live web demos are deployed
from the same release.
