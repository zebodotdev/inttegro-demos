# Inttegro demos 1.4.1

This presentation patch gives every README deployment action one coherent
visual system. It does not change the checkout integration or application
runtime introduced in 1.4.0.

## Changes

- Replaces mismatched vendor badges with a shared 184-by-32-pixel button family.
  Every action now has the same border, corner radius, typography, spacing, and
  white surface while retaining the provider's recognizable mark.
- Orders active README actions alphabetically by provider, matching the public
  catalogue and Studio.
- Keeps every action's destination unchanged and pinned to the immutable 1.4.1
  release or deployment reference.
- Rewrites shared button assets to immutable raw release URLs when producing
  flattened deployment branches, so their READMEs render correctly outside the
  suite directory structure.

## Verification

The repository contract checks that every launchable provider uses its shared
button asset, all six button assets are present, mobile demos use the same
companion-backend actions, and deployment-reference preparation preserves the
buttons. The SVG family was rendered together and visually inspected at double
resolution before release.

The container and checkout implementations are unchanged from 1.4.0; their
verification status and documented platform boundaries remain the same.
