# Inttegro demos 1.7.0

Release 1.7.0 makes the public demo suite a stronger implementation reference
and a more convincing product experience. Web demos now consume the published
Inttegro JavaScript packages for hosted, embedded, and modal Checkout, while
each story receives an art direction suited to the product it represents.

## First-party web integration

- Next.js and RedwoodSDK use `@inttegro/react` 0.2.0.
- Nuxt uses `@inttegro/vue` 0.2.0.
- Server-rendered demos bundle the public `@inttegro/js` 0.2.0 loader while
  keeping order creation and API credentials on the trusted server.
- Registry-backed lockfiles make the browser bundle and framework adapters
  reproducible from a clean checkout.

The customer can choose hosted-page, embedded, or modal Checkout without
changing the server-side Order contract. The presentation layer receives only
the public Checkout URL returned after the server finalizes the Order.

## Distinct demo stories

- Kora Market becomes an editorial craft storefront with a tactile product
  story and a focused cart sheet.
- Afterglow Sessions becomes a kinetic event poster with a richer lineup,
  venue story, and ticket-stub checkout.
- Ledgerline becomes a document-first invoice experience with project evidence,
  lifecycle detail, and structured totals.
- Openfield becomes a proof-led community campaign with measurable outcomes,
  field updates, and public milestones.
- The SwiftUI, Compose, Flutter, and React Native demos carry the same Kora
  direction into platform-native layouts.

New release artwork is original to the repository and is validated alongside
the shared UI and Checkout assets.

## Release guarantees

The suite tag and all 15 per-demo tags resolve to one immutable signed commit.
Reader-owned deployment links target release-specific branches, and Studio
links documentation and source examples to the same version.

Spring Boot remains published as source but unavailable for live or remote
builds until the Inttegro Java SDK dependency is public.
