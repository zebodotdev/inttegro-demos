# Inttegro demos 1.8.3

Release 1.8.3 ensures the FastAPI demo cannot retain an older Angular Checkout
bundle after the server deployment has advanced.

## FastAPI asset delivery fix

- The Angular entry point now has an explicit cache-version token in the
  server-rendered page.
- Railway-served copies of the bundle require revalidation, preventing a CDN
  from pairing current FastAPI code with stale browser integration code.
- The application-owned modal and embedded Checkout continue to use the
  published `@inttegro/angular` 0.2.0 adapter and Inttegro-hosted runtime.
- Hosted-page Checkout remains the resilient server-side POST and `303`
  redirect path.

## Verification

The fresh deployment origin created a finalized production Order and opened
the modal with one Inttegro Pages iframe. The iframe used the public Order
reference, the deployment origin, locale, theme, and SDK version `0.2.0`.

## Release guarantees

The suite tag and all 16 per-demo tags resolve to one immutable signed commit.
Reader-owned deployment links target release-specific branches, and Studio
links documentation and source examples to the same version.
