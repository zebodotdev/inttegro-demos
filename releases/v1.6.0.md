# Inttegro demos 1.6.0

Version 1.6.0 lets readers compare all three supported web Checkout
presentations inside every server-backed demo.

## Checkout presentations

- **Embedded** mounts Inttegro Checkout in the host application's order flow.
- **Modal** mounts the same Checkout inside an accessible app-owned dialog.
- **Hosted page** retains the full-page Inttegro Pages handoff and remains the
  no-JavaScript fallback.

Each presentation pays the same server-created, finalized Order. The browser
receives only its Order ID for embedded and modal Checkout; API credentials,
catalog selection, prices, line items, and finalization remain on the trusted
server. JSON responses are marked `Cache-Control: no-store`, while ordinary
form submissions retain a safe `303 See Other` redirect.

## Runtime and interface quality

- The shared browser module loads the fixed Inttegro-hosted runtime and never
  bundles or mirrors executable Checkout code.
- Modal sessions restore the owning application dialog, destroy their Checkout
  controller on close, and respect reduced-motion preferences.
- Responsive presentation controls inherit each demo's visual language and
  preserve the native form as a resilient baseline.
- Every framework release manifest now exposes the presentation client as a
  stable, deeply linkable integration entry point for Studio.

## Release contract

This release contains 15 tagged demos. The suite tag and every per-demo tag
point to the same signed release commit. Reader deployment branches are
regenerated from that immutable source, and the live web demos are deployed
from the same release.
