# Inttegro demos 1.8.2

Release 1.8.2 fixes the FastAPI demo's Angular Checkout presentation after the
server creates an Order.

## FastAPI Angular fix

- The Angular island now triggers rendering after its asynchronous Order
  response, including in zoneless Angular applications.
- Embedded Checkout appears in the event page as soon as the finalized Order
  is available.
- Modal Checkout opens the application-owned accessible dialog only after
  Angular has rendered the official `@inttegro/angular` component.
- Hosted-page Checkout remains the resilient server-side POST and `303`
  redirect path.

## Runtime compatibility

The live framework demos were exercised against the restored Inttegro `0.2.0`
hosted runtime required by the currently published Angular and Svelte packages.
The server-held API key and trusted Order-creation boundary are unchanged.

## Release guarantees

The suite tag and all 16 per-demo tags resolve to one immutable signed commit.
Reader-owned deployment links target release-specific branches, and Studio
links documentation and source examples to the same version.
