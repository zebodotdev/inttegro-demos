# Inttegro demos 1.5.0

Version 1.5.0 adds two complete Openfield fundraising applications and makes
the Python demos genuinely asynchronous at their network boundary.

## New demos

- **NestJS** presents Openfield as a portable Node service with dependency
  injection, validated contribution tiers, a server-owned product lookup, and
  hosted Inttegro checkout.
- **RedwoodSDK** presents the same campaign as a Cloudflare-native application,
  keeping the checkout boundary inside its Worker while preserving the same
  trusted catalog and order contract.

Both applications include original campaign artwork, polished responsive
interfaces, extensive `INTTEGRO:*` commentary, automated checkout tests, and
reader-owned deployment configuration appropriate to their runtimes.

## Python Workers

- Django and FastAPI now use Inttegro Python SDK 6.3.0 and
  `AsyncInttegroClient`.
- Both applications use ASGI-native handlers and include host-neutral
  Cloudflare Python Workers configurations.
- Django includes a narrowly documented compatibility layer for synchronous
  framework hooks that are known not to perform blocking I/O in this demo.
- Source layouts, static assets, container builds, tests, and deployment
  documentation now describe the same runtime contract.

## Release contract

This release contains 15 tagged demos. Each framework tag and the suite tag
points to the same signed release commit, and every deploy action starts from
an immutable `deploy-{demo}-v1.5.0` branch where the target provider supports
that application.
