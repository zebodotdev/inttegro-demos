# Inttegro demos 1.3.0

This release expands reader-owned deployment paths and improves the native SDK
examples without changing the checkout integration contract.

## Changes

- Adds one-click Google Cloud Run deployment contracts for Express, Django,
  FastAPI, Go, Rails, and Laravel. Each flow builds the released Dockerfile,
  prompts for the required Inttegro configuration, limits scale, and records
  the provider-assigned HTTPS origin for checkout returns.
- Publishes shareable Railway templates for the same six server demos, pinned
  to immutable deployment branches and exact release commits.
- Shows official provider logos, orders available providers alphabetically
  ahead of unavailable providers, and keeps unsupported targets visible but
  disabled with machine-readable reasons.
- Adds genuine native payment-sheet captures to the Android Compose example
  and makes saved-method captions describe what the customer will recognize.
- Advances suite, per-demo, and deployment references to version 1.3.0. Older
  releases remain unchanged for existing Studio permalinks.

AWS App Runner remains unavailable as a public one-click target: AWS no longer
accepts new App Runner customers, source deployment depends on an
account-specific source connection, and this release does not publish ECR
Public images. Next.js and Nuxt also remain off Cloud Run until their release
artifacts include tested portable containers. Spring Boot deployment remains
gated on publication of Inttegro Java SDK 5.0.0.

## Verification

The repository-wide demo contract check and Go test suite passed. The contract
check validates release metadata, immutable deployment references, provider
configuration, required environment values, catalog ordering, source
documentation, and SDK naming. The application integration paths and
previously exercised Dockerfiles are unchanged from release 1.2.3.

Cloud Run targets are marked prepared, not verified. Verification requires a
fresh deployment from the public button in a reader-owned Google Cloud project
and a complete checkout smoke test under the gates in `DEPLOYING.md`.

## Release safety

Deployment contracts contain no Inttegro credentials. Every public flow asks
the reader for a dedicated server-side API key and keeps it out of source,
browser bundles, mobile applications, URLs, and release artifacts.
