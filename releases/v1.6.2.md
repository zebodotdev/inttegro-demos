# Inttegro demos 1.6.2

Release 1.6.2 completes first-party hosting for the Openfield demonstrations.
NestJS now runs at `nestjs-demo.inttegro.dev` on Railway, and RedwoodSDK runs
at `redwoodsdk-demo.inttegro.dev` on Cloudflare Workers.

## Openfield live demonstrations

Both applications present the same Riverbend Learning Garden contribution
flow while keeping their framework-native architecture:

- NestJS uses controllers, dependency injection, DTO validation, and a
  portable Node container service.
- RedwoodSDK uses React Server Components and a Cloudflare Worker request
  boundary.

Each live application offers embedded, modal, and hosted-page Checkout. The
browser submits only a bounded contribution tier; the trusted server resolves
the configured Product and Price, supplies the readable `OPENFIELD-…` order
number, and creates the finalized Order.

## Release guarantees

The suite tag and all 15 per-demo tags resolve to one immutable signed commit.
Reader-owned deployment links target release-specific branches, and Studio
links documentation and source examples to the same version.

Spring Boot remains published as source but unavailable for live or remote
builds until the Inttegro Java SDK dependency is public.
