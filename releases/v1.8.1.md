# Inttegro demos 1.8.1

Release 1.8.1 corrects the production reverse-proxy trust boundary for the
Astro demo introduced in 1.8.1.

## Astro production fix

- Astro now accepts `X-Forwarded-Host` only for the published
  `https://astro-demo.inttegro.dev` origin.
- Astro's built-in same-origin protection remains enabled, so browser checkout
  requests work behind Railway without widening the accepted host set.
- The live deployment, immutable deployment branch, and Studio source links
  advance together to this patch release.
- The shared static browser loader now pins the available hosted runtime at
  `https://js.inttegro.com/inttegro.js@0.3.0` and rejects a mismatched global.

## Release guarantees

The suite tag and all 16 per-demo tags resolve to one immutable signed commit.
Reader-owned deployment links target release-specific branches, and Studio
links documentation and source examples to the same version.
